# 闪电分镜 · 教学克隆版

一个用于学习、演示和二次研究的前端复刻项目，复刻对象是中文影视前期协作 SaaS「闪电分镜」的项目工作区。项目不包含真实后端，所有项目、分镜、拍摄计划、通告和联系人都保存在浏览器 `localStorage` 中。

> 本项目为非官方教学作品，与 mediastory / 闪电分镜官方无关联。界面和流程仅用于技术学习，请勿将演示内容用于商业用途，也不要上传真实的未授权素材。

## 在线演示

GitHub Pages：<https://chi2tseng.github.io/mediastory-clone/>

`gh-pages` 分支存放构建产物；主分支保留完整源码与素材。

## 快速开始

环境：Node.js 20+，npm。

```bash
npm install
npm run dev -- --port 5183
```

打开 <http://localhost:5183>。按需求，登录流程已移除，打开后直接进入「我的项目」，当前演示用户为「创作者」。

生产构建与预览：

```bash
npm run build
npm run preview
```

发布到 GitHub Pages 子路径时使用：

```bash
npm run build:pages
```

构建产物在 `dist/`，其中资源路径会自动带上 `/mediastory-clone/` 前缀。

## 已实现的流程

### 项目

- 项目卡片、搜索、按自定义 / 创建时间 / 名称排序
- 新建项目（项目标志 + 简洁 / 专业模板）
- 重命名、复制项目、打开项目
- 移入回收站（带确认）、在回收站恢复、永久删除（带确认）
- 项目封面自动取第一个有画面的镜头，显示镜头数与总时长

### 制作分镜

- 动态分镜表格：镜号、画面、景别、时长、内容、备注等字段
- 单元格直接编辑，修改即时保存
- 新建镜头、批量添加 5 个镜头、复制 / 插入 / 删除镜头
- 按住左侧手柄拖拽调整镜头顺序
- 批量模式：全选、取消选择、批量删除
- 分镜设置：画幅比例（16:9、2.35:1、4:3、1:1、9:16）
- 列设置：显示 / 隐藏列、调整列顺序
- 图片上传，自动压缩大图并保存为 Data URL

### 故事板

- 按镜头顺序展示画面、景别、时长、内容、备注
- 2 / 3 / 4 列切换，桌面端默认 4 列
- 显示设置：景别、时长、内容、备注开关
- 卡片大小缩放
- 镜头编辑弹窗、画面直接上传
- 故事板预览
- 全屏放映模式：左右箭头 / 键盘方向键切换，Esc 退出

### 拍摄计划

- 未规划镜头池，显示未分配镜头
- 勾选镜头后加入计划，或直接拖拽镜头到计划
- 新建拍摄计划（名称、日期、地点、备注）
- 计划卡片统计镜头数与总时长
- 编辑 / 删除计划，从计划移除镜头
- 演示数据包含 Day 1 夜景外景、Day 2 内景 + 产品

### 拍摄通告

- 通告列表、新建、编辑、预览
- 三步编辑：基本信息 → 完善通告（人员 / 天气 / 时间）→ 计划与日程
- 从联系人选择人员并自动带出电话
- 勾选要覆盖的拍摄计划，镜头清单自动附在通告后
- A4 竖版打印 / 另存为 PDF，打印时隐藏应用界面
- 通告页显示日期、集合时间、地点、人员、日程、镜头清单和备注

### 协作与分享

- 项目分享链接（本地演示地址）
- 复制链接、选择「可编辑 / 仅查看」权限
- 邀请成员（演示：写入本地成员列表）
- 成员角色调整、移除成员
- 拥有者不可移除

### 导出

- 内容：分镜 / 故事板 / 拍摄计划 / 拍摄通告
- 格式：PDF（浏览器打印）/ Excel / CSV（仅分镜）
- 页面设置：A4 横 / 竖、文字大小、画面大小、最大列数、导航栏颜色
- 拍摄通告可选择具体通告，并选择是否附上拍摄计划
- 导出预览与打印样式隔离，打印输出为干净白底

### 模板与联系人

- 6 套内置模板：简洁分镜、专业分镜、广告 TVC、微电影 / 短片、MV / 音乐短片等
- 使用模板创建项目，自动生成示例镜头和对应列
- 联系人增删改，联系人数据用于拍摄通告

## 数据与持久化

- 存储键：`mediastory-clone-v1`
- 首次打开会写入演示数据；之后一直读取本地数据
- 重置演示数据（浏览器控制台）：

```js
localStorage.removeItem('mediastory-clone-v1')
location.reload()
```

演示数据：

- 「城市之光 · 宣传片」：6 个镜头、2 个拍摄计划、1 份拍摄通告、3 位联系人
- 「未命名短片 · 分镜草稿」：1 个镜头

## 打印 / PDF

导出页和拍摄通告都使用浏览器原生打印生成 PDF：

1. 点击导出 / 打印后，在浏览器打印窗口选择「另存为 PDF」。
2. 纸张选择 A4，边距 10mm，勾选「背景图形」以保留封面和色块。
3. 导出页会根据「横 / 竖」动态写入 `@page`；拍摄通告固定 A4 竖版。

CSV 带 UTF-8 BOM，可直接用 Excel 打开中文内容。

## QA 脚本

项目内包含基于 `puppeteer-core` 的端到端检查和 PDF 验证脚本。运行前先启动开发服务器（端口 5183），并确认本机 Chrome 路径：

```text
C:/Program Files/Google/Chrome/Application/chrome.exe
```

```bash
npm run qa              # 主流程：制作 / 故事板 / 计划 / 通告 / 模板 / 联系人（56 项）
npm run qa:flows        # 项目管理 / 放映 / 上传 / CSV / 新建计划与通告 / 联系人（53 项）
npm run qa:print        # 导出 PDF、通告打印、A4 横竖版检查
npm run qa:orientation  # 导出方向切换与 PDF 尺寸检查
npm run qa:layout       # 桌面 / 390px 移动端布局溢出检查
```

最近一次检查（2026-10-27）：桌面与 390px 移动端路由全部加载，无 console 错误、失败请求或破图；制作分镜的单元格编辑、拖拽排序、批量选择、行菜单插入 / 复制 / 删除、菜单边界与滚动关闭均通过；拍摄计划、故事板、协作弹窗和导出页设置交互均通过。`qa2.cjs` / `qa3.cjs` 为早期脚本，部分选择器已随界面重构过期，保留作历史参考。

截图和 PDF 输出在系统临时目录的 `opencode/clone-shots/` 下。

## 已知限制

这是教学用的前端复刻，不是完整商业产品：

- 没有后端、真实账号体系、云同步或真正的多人实时协作；登录已按需求移除。
- 分享链接只生成本地演示地址，没有实现 `/join/:token` 的加入流程和权限强制。
- 「创建新项目 / 组」目前只会创建项目，项目分组 / 文件夹尚未实现。
- 账号设置、通知、反馈与订单等入口为演示提示。
- 项目排序中的「自定义」目前保留默认顺序，没有实现手动拖拽排序。
- PDF 依赖浏览器打印对话框，字体和分页会随浏览器 / 系统略有差异。
- CSV 只支持分镜表；故事板、计划和通告请使用 PDF。
- 移动端已做基础响应式（390px 无横向溢出、底部项目页签、故事板双列、计划单列），但复杂表格编辑仍建议在桌面端使用。
- 图片以 Base64 保存在 `localStorage`，大量高清图可能触及浏览器存储上限。
